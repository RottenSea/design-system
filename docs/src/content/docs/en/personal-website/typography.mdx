Three faces, each with one job: a serif for display, a sans for everything people read and click, and a mono for code. Each family lists a Chinese face after the Latin one, so mixed text sets in both.

## Faces

- **Display** is Noto Serif SC at weight 400 only, with negative tracking that grows with the size. A bold serif is off-brand.
- **Body**, navigation, buttons and labels are Manrope with Noto Sans SC: 400 for paragraphs, 500 for labels and emphasis.
- **Code** is Maple Mono.
- **Math** is Noto Sans Math, falling back to the system's math font.

Emphasis grows by size, not weight: reach for a bigger serif before a heavier one. The uppercase micro-label is the only type that is not in sentence case.

The fonts load from Google Fonts and jsDelivr without holding up the page; see the [overview](../) for the Fonts component.

## Scale

Each style is a class, such as `.ds-display-xl`, and a set of variables, one per property. On screens narrower than 768px the three largest display sizes step down, with their tracking redrawn for the smaller size, while `display-sm` stays put. This is a token change, so every class and component follows without a media query of its own.
