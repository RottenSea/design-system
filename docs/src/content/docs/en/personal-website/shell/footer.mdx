The dark band that closes every page, in both themes: the site's name, columns of links, and a line for the copyright.

<Example system="personal-website" name="footer" title="Footer with two columns and a copyright line" viewport={1280} />

## When to use

Once, at the end of every page.

## On a page

```astro
<Footer
  brand="Field Notes"
  columns={[{ title: "Site", links: [{ label: "Blog", href: "/" }] }]}
  note="© 2026 Field Notes."
>
  <Logo slot="logo" width={24} height={24} aria-hidden="true" />
  <img slot="brand-extra" src="/badge.svg" alt="Written by a person" width="131" height="42" />
</Footer>
```

The `logo` slot puts a mark before the name; the `brand-extra` slot goes under them, for a badge or a short line. A note with links in it goes in the `note` slot instead.

## Anatomy

`--surface-dark` with 64px above and below, within `--container-max`. First a column with the mark and the site's name at the top and the `brand-extra` slot at the bottom, then a column for each list of links under its uppercase micro-label. All of them start from the left. The link columns are as wide as their links and 72px apart; the brand column leads, with 96px after it. The link columns set the height, and `brand-extra` sits level with the end of the longest. Across the bottom, the note above a hairline. Below 768px the brand column stacks above the links, which go two across.

## States

| Width | Layout |
| --- | --- |
| Above 768px | The brand column and one per list of links, side by side |
| Below 768px | The brand column, then the links two across |

## Accessibility

Each column is a `<nav>` named by its title. A link to another site opens a new tab, with the arrow and a note for screen readers. The note is in `--text-on-dark-soft`, which keeps 4.5:1 on the footer in both themes.

## API

[`Footer.astro`](https://github.com/RottenSea/design-system/blob/main/systems/personal-website/src/components/layout/Footer.astro). Ported from the handoff, with links as `{ label, href }`. The handoff puts the name above four columns of links at every width; here the brand has a column of its own beside them. The handoff's note colour, `--text-muted-soft`, is 3.5:1 on the footer in the dark theme, so the note uses `--text-on-dark-soft`.
