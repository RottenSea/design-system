Each page says when to use the component, how to write it in a post, and what it looks like. The examples run in a frame with only this system's CSS, and follow the light or dark theme of these docs.

| Component | In a post | What it does |
| --- | --- | --- |
| [Admonition](./admonition/) | `:::tip` and four more, `:::details` | Pulls one point out of the reading flow |
| [Spoiler](./spoiler/) | `:spoiler[...]`, `:::spoiler` | Covers an answer until the reader asks for it |
| [Abbreviation](./abbreviation/) | `:term[...]{note="..."}` | Gives a term a one-line explanation |
| [Steps](./steps/) | `:::steps` | Numbers a procedure |
| [CodeBlock](./code-block/) | A code fence | Shows code with its filename, line numbers and copy |
| [TableScroll](./table-scroll/) | A Markdown table | Lets a wide table scroll |
| [OptionGroup](./option-group/) | `:::code-group` | Shows one of several flavours of an instruction |
| [FileTree](./file-tree/) | `:::file-tree` | Shows part of a project's structure |
| [Figure](./figure/) | An image on a line of its own | Shows an image with a caption, zoom and a placeholder |
| [ImageGrid](./image-grid/) | `:::gallery` | Shows several images in a grid |
| [VideoEmbed](./video-embed/) | `::video` | Plays a Bilibili, YouTube, AcFun or Vimeo video once the reader presses play |
| [MathBlock](./math-block/) | `$...$`, `$$...$$` | Shows a formula, typeset at build time |
| [Mermaid](./mermaid/) | A `mermaid` code fence | Draws a diagram in a DiagramFrame |
