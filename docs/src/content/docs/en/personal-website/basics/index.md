The small pieces the site's larger components are made of. A post never writes them; they come with PostShare, SettingsMenu, the nav and Abbreviation. The examples show each one the way the site uses it.

| Component | Where the site uses it | What it does |
| --- | --- | --- |
| [Button](./button/) | PostShare and its dialog | A labelled action |
| [IconButton](./icon-button/) | The nav, the settings, back to top, closing a dialog | An action shown by one icon |
| [Dialog](./dialog/) | The share poster | A modal card over a dimmed page |
| [Snackbar](./snackbar/) | "Link copied" | A one-line message that leaves by itself |
| [Tooltip](./tooltip/) | Abbreviation | A one-line note over a term |
| [SegmentedControl](./segmented-control/) | The theme in SettingsMenu | Two to four options, one chosen |
| [Switch](./switch/) | Reduce motion in SettingsMenu | A setting that applies at once |
