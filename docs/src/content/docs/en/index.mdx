## Docs spec

How a design system in this repository is documented: the entries and sections its docs are made of, what a token, theme or component page says, the accessibility rules it meets, and how versions and writing are handled. It is a summary of the [Design System Doc Spec (DSDS)](https://designsystemdocspec.org/) and the other standards it links.
