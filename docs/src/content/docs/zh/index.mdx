## 文档规范

[Design System Doc Spec（DSDS）](https://designsystemdocspec.org/) 是一份给 design system 写文档的规范：文档由哪些部分组成，讲 token、主题、组件的页面各写什么，以及每个事实从哪里来。事实本身它交给其他标准：token 和主题用 DTCG，无障碍用 WCAG 和 ARIA Authoring Practices，版本用语义化版本（Semantic Versioning）。

这个网站的文档规范是 DSDS 和这些标准的概要，为本仓库的系统而写。每个系统的文档都照它写；概要和标准不一致时，以标准为准。

## Design system

design system 是一个产品共用的一整套设计决定。token 把颜色、文字、间距、动效这些数值存成数据；样式和组件把它们用起来；准则说明什么时候用什么。网站把它当作一个包安装，不在自己的代码里重复这些决定。

这里的每个系统有自己的栏目：它做什么、怎样安装，它的基础（数值从 token 文件读出），以及带实时示例的组件。
