## 文档规范

本仓库中的 design system 怎样写文档：文档由哪些条目和小节组成，token、主题、组件页面写什么，要满足哪些无障碍规则，版本和写作怎么处理。它是 [Design System Doc Spec（DSDS）](https://designsystemdocspec.org/) 和它链接的其他标准的概要。
