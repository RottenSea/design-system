网站上大组件用到的小零件。文章里不会直接写它们，它们跟着 PostShare、SettingsMenu、导航栏和 Abbreviation 一起出现。每个示例都是网站实际用它的样子。

| 组件 | 网站在哪里用 | 做什么 |
| --- | --- | --- |
| [Button 按钮](./button/) | PostShare 和它的对话框 | 带文字的操作 |
| [IconButton 图标按钮](./icon-button/) | 导航栏、设置、回到顶部、关闭对话框 | 只用一个图标表示的操作 |
| [Dialog 对话框](./dialog/) | 分享海报 | 压暗页面、居中的一张卡片 |
| [Snackbar 消息条](./snackbar/) | “Link copied” | 一行提示，过一会儿自己消失 |
| [Tooltip 提示气泡](./tooltip/) | Abbreviation | 术语上方的一行说明 |
| [SegmentedControl 分段控件](./segmented-control/) | SettingsMenu 里的主题 | 两到四个选项选一个 |
| [Switch 开关](./switch/) | SettingsMenu 里的 Reduce motion | 拨一下立刻生效的设置 |
