## 时长和曲线

四种时长：`--motion-fast` 用于控件的颜色变化，`--motion-base` 用于底色变化，`--motion-slow` 用于形状变化（例如一段内容折叠），`--motion-entrance` 只属于对话框出现，别处不用。三条曲线：`--ease-enter` 用于出现，`--ease-exit` 用于消失，`--ease-move` 用于原地改变大小。

`motion.css` 把它们组合成四种过渡：`--transition-tint`、`-surface`、`-fade` 和 `-collapse`。先用这几个，再考虑手写时长。

## 三种基本动效

所有会变的列表都用三个类：`.ds-reveal-in`（从下方 8px 淡入）、`.ds-fade-out`（只改透明度）和 `.ds-collapse`（改高度）。一个列表有增有减时按固定顺序：要走的先淡出，剩下的移动位置，新来的淡入。`--motion-shift` 是唯一的位移距离，只在淡入时用。

没有滚动触发的出现、没有视差、没有骨架屏闪光，也没有页面切换动画。唯一循环的动画是不确定进度条，它总带着文字说明。

## 减少动效

两种情况下动效都缩短到 1ms：系统设置里的 `prefers-reduced-motion`，以及网站在 `<html>` 上设的 `data-reduce-motion="true"`。任何时候都可能开着其中一个，所以动效只用来确认操作，不单独传达信息。
