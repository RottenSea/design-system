动效和系统的其他部分一样安静。变的是颜色和透明度，东西很少移动，也不会缩放、弹跳或回弹。

## 时长和曲线

四种时长：`--motion-fast` 用于控件的颜色变化，`--motion-base` 用于底色变化，`--motion-slow` 用于形状变化（例如一段内容折叠），`--motion-entrance` 只属于对话框出现和切换主题，别处不用。三条曲线：`--ease-enter` 用于出现，`--ease-exit` 用于消失，`--ease-move` 用于原地改变大小。

`motion.css` 把它们组合成四种过渡：`--transition-tint`、`-surface`、`-fade` 和 `-collapse`。先用这几个，再考虑手写时长。

## 三种基本动效

所有会变的列表都用三个类：`.ds-reveal-in`（从下方 8px 淡入）、`.ds-fade-out`（只改透明度）和 `.ds-collapse`（改高度）。一个列表有增有减时按固定顺序：要走的先淡出，剩下的移动位置，新来的淡入。`--motion-shift` 是唯一的位移距离，只在淡入时用。

没有滚动触发的出现、没有视差，也没有骨架屏闪光。换页时的淡入淡出见[页面切换](../settings/page-transitions/)，由网站自己引入。唯一循环的动画是不确定进度条，它总带着文字说明。

## 切换主题

主题是每页一个的 store：`@rottensea/ds-personal-website/scripts/theme` 里的 `themeStore()`，只有它能改主题。它存着读者的选择（浅色、深色、跟随系统）和实际用的主题，由它写 `data-theme`、把选择存进 localStorage、加渐变。选择是跟随系统时它跟着系统变，网站的别的标签页改了选择时它也跟着变。ThemeToggle 和 SettingsMenu 用 `set()` 提出切换；SettingsMenu、Mermaid 和 SharePoster 用 `subscribe()` 订阅，所以面板上显示的总是当前的选择，主题真的变了图才重画，每次只画一次。

```ts
import { themeStore } from "@rottensea/ds-personal-website/scripts/theme";

const theme = themeStore();
theme.set("dark");
theme.subscribe((state, previous) => {
  if (state.theme !== previous.theme) redraw();
});
```

每次切换，页面上所有颜色都一起过渡，用 `--motion-entrance` 和 `--ease-move`。`tokens.css` 把深色主题会改的变量列在 `--theme-variables` 里，并用 `@property` 把它们注册成颜色或百分比。渐变的每一帧，store 都把这些变量往新主题的值推进一步，写在 `<html>` 上，每个元素读到的都是渐变中的值。之所以由 store 自己写，而不让 CSS 过渡去改，是因为 Chrome 画已访问的链接时，不接受正在被过渡或动画改变的变量（[crbug.com/569257985](https://issuetracker.google.com/issues/569257985)）：已访问的链接和里面的文字会取链接外面那个元素的颜色，到渐变结束才跳回来。这段时间 `<html>` 上有 `data-theme-fade`，元素自己的过渡都关掉，否则它每一帧都会重新开始，落在其他颜色后面。在浅色值和深色值之间二选一的颜色，用 `color-mix()` 按 `--theme-dark` 混合两个值：浅色主题里是 0%，深色主题里是 100%，所以也会渐变。这只适用于两个值本身不变的情况，比如 Shiki 给一个词的两种颜色。如果两个值都是主题颜色，它们自己也在渐变，混出来的颜色会比页面跑得快，所以这种颜色直接做成主题里的 token，比如 CodeBlock 用的 `surface.code`。`light-dark()` 跟着 `color-scheme` 走，而 `color-scheme` 没法渐变。

脚本画出来的东西不是 CSS 颜色。Mermaid 图和 SharePoster 用 `themeValues()` 读新主题的颜色，因为渐变过程中 `getComputedStyle()` 读到的是半路的颜色。它们按新主题重画，再用同一个模块里的 `fadeIn` 让新图在旧图上淡入。

脚本自己直接写 `data-theme` 时，store 照样当成一次切换，加渐变、通知订阅者，开发模式下在控制台提示。如果那段脚本写完马上读样式，渐变会来不及，所以正路是 `set()`。

## 减少动效

两种情况下动效都缩短到 1ms：系统设置里的 `prefers-reduced-motion`，以及网站在 `<html>` 上设的 `data-reduce-motion="true"`。任何时候都可能开着其中一个，所以动效只用来确认操作，不单独传达信息。

有两个背景在这两种情况下都照样在动：[Starfield](../shell/starfield/) 和 [DotGlobe](../shell/dot-globe/)。它们漂得又慢又匀，没有闪动和跳动，网站也希望它们一直是活的。
