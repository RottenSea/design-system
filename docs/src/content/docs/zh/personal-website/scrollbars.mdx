title: 滚动条
description: 页面和面板里的滚动条：位置一直留着，颜色跟着主题渐变。
---

## 留出位置

`base.css` 在 `<html>` 上写了 `scrollbar-gutter: stable`，不管页面能不能滚动，右边都留着滚动条的宽度。这样短页面和长页面的内容在同一个位置居中，内容变长出现滚动条或者面板锁住滚动时，页面也不会左右移一下。只留右边，因为两边都留的话，每条通栏的深色带旁边会多出一条底色。

页面里的滚动区，只有打开时内容会变的才留位置。比如 SearchPanel 的结果列表，结果一多出现滚动条，每一行也不会往左挤。目录、菜单和对话框的内容是固定的，不留，否则没有滚动条时右边会空出一条。

文档站的示例页也不留。示例不滚动，留了会在右边空出一条，露出后面的文档页。

## 颜色

滚动条是细的，滑块用 `--text-muted-soft`，轨道透明，露出所在表面的底色。`scrollbar-color` 继承的是算好的颜色，所以里面的滚动区默认和页面一样。深色表面上的滚动区要自己设，CodeBlock 就用它自己的次要文字色，在暖藏青色上也看得清。

## 换主题

`--text-muted-soft` 是主题变量之一，换主题时滑块和页面上其他颜色一起渐变。不支持 `scrollbar-color` 的浏览器按 `color-scheme` 画自己的滚动条，而主题 store 在渐变结束时才改 `color-scheme`，所以这些浏览器里的滚动条会在最后一下换过去。

## 在网站里

| 要做的 | 写法 |
| --- | --- |
| 新加一个打开后内容会变的竖向滚动区 | `overflow-y: auto; scrollbar-gutter: stable;` |
| 深色表面上的滚动区 | `scrollbar-color: var(--text-on-dark-soft) transparent;` |
