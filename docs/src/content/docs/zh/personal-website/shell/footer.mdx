每一页收尾的深色一条，两种主题下都是深色：网站名、几列链接、一行版权。

<Example system="personal-website" name="footer" title="两列链接和一行版权的页脚" viewport={1280} />

## 什么时候用

每页一个，放在最后。

## 页面里怎么写

```astro
<Footer
  brand="Field Notes"
  columns={[{ title: "Site", links: [{ label: "Blog", href: "/" }] }]}
  note="© 2026 Field Notes."
>
  <Logo slot="logo" width={24} height={24} aria-hidden="true" />
  <img slot="brand-extra" src="/badge.svg" alt="Written by a person" width="131" height="42" />
</Footer>
```

`logo` 插槽在网站名前面放标志；`brand-extra` 插槽在它们下面，放徽章或一行短字。那一行说明里要放链接时，改用 `note` 插槽。

## 结构

底色 `--surface-dark`，上下各 64px，宽度不超过 `--container-max`。左边单独一列：标志和网站名，下面是 `brand-extra` 插槽。右边是并排的几列链接，列名是大写小字，靠右对齐。最下面一条细线上是那一行说明，横跨整个宽度。窄于 768px 时品牌那一列在上，链接在下面，两列一行。

## 状态

| 宽度 | 列数 |
| --- | --- |
| 宽于 1080px | 四列 |
| 768 到 1080px | 两列 |
| 窄于 768px | 一列 |

## 无障碍

每一列是一个 `<nav>`，名字是列名。指向其他网站的链接在新标签页打开，带箭头，并给读屏软件一句说明。最下面那一行用 `--text-on-dark-soft`，在两种主题的页脚上对比度都在 4.5:1 以上。

## API

[`Footer.astro`](https://github.com/RottenSea/design-system/blob/main/systems/personal-website/src/components/layout/Footer.astro)。从交付包移植，链接写成 `{ label, href }`。交付包把网站名放在四列链接上面，这里让品牌单独占左边一列。交付包那一行用的 `--text-muted-soft` 在深色主题的页脚上只有 3.5:1，所以换成了 `--text-on-dark-soft`。
