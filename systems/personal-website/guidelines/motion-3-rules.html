Animates

  • Tint on press, tab select, link and row hover
  • Nav going transparent to solid on scroll
  • Banner, drawer, and dialog scrim opacity
  • Height on a collapsing year or widget
  • List membership — the three primitives
  • Back-to-top appearing, on opacity

Never

  • Scale, shrink, or lift on press
  • Scroll-triggered reveals and parallax
  • Springs, bounces, overshoot — except the one Dialog entrance
  • Looping or attention-seeking motion; no marquee
  • Skeleton shimmer; a static cream block is the loading state
  • Page transitions on navigation
Two levels of degrade, both to 1ms: the OS setting via prefers-reduced-motion, and a site switch the page flips as data-reduce-motion="true" on the html element. Anything that only conveys meaning while moving is therefore already broken — motion is confirmation, never information.
