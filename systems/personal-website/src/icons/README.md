# Icons

Icons the components draw, imported as SVG components so they are inlined when a page is built.
They are copied unchanged from [Tabler Icons](https://tabler.io/icons) 3.49.0, the icon set the
brand design handoff uses, under the MIT licence, Copyright (c) 2020-2026 Paweł Kuna. They come
from the outline set, except `player-play-filled.svg` and `pinned-filled.svg`, which are from the filled set.

Add an icon by copying its file from the `@tabler/icons` package's `icons/outline/` folder, or
from `icons/filled/` with `-filled` added to the name.
