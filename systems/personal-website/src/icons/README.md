# Icons

Icons the components draw, imported as SVG components so they are inlined when a page is built.
They are copied unchanged from [Tabler Icons](https://tabler.io/icons) 3.49.0 (outline set), the
icon set the brand design handoff uses, under the MIT licence, Copyright (c) 2020-2026 Paweł Kuna.

Add an icon by copying its file from the `@tabler/icons` package's `icons/outline/` folder.
